# Whole-Cell Biosensor Fingerprint ML Platform

## Project Overview

This project develops and validates a machine-learning framework for identifying agricultural contaminants from luminescent whole-cell biosensor responses.

The platform analyzes time-series bioluminescence measurements generated by multiple bacterial biosensor strains exposed to different contaminants and produces contaminant-specific fingerprints for classification and interpretation.

---

## Research Question

Can luminescence fingerprints generated by engineered whole-cell biosensors be used to accurately identify environmental contaminants and their associated exposure patterns?

---

## Biological Context

Whole-cell biosensors respond to chemical stressors through changes in luminescence output. Different contaminants may induce distinct temporal response patterns that can be captured and analyzed using machine learning.

Target contaminants include:

* Boric Acid
* DEET
* Diazinon
* Metaldehyde
* Propoxur
* Trimethoprim

Biosensor strains:

* BL011
* BL027
* BL029
* BL030
* BL031
* BL032

## Key Findings

* Random train/test classification performance reached approximately 98%.
* LOEO validation revealed substantial experiment-to-experiment variability.
* BL027 emerged as the strongest overall biosensor strain.
* Different contaminants exhibited strain-specific recognition patterns.
* Advanced temporal feature engineering improved experiment-independent performance.
