# Reproducibility Guide

## Purpose

This document describes how an independent reviewer can reproduce the results generated by the Whole-Cell Biosensor Fingerprint ML Platform.

---

# System Requirements

Recommended environment:

* Windows 10/11
* Python 3.12+
* Git
* VS Code (recommended)

---

# Repository Setup

Clone repository:

```bash
git clone <repository_url>
cd biosensor_fingerprint_ml
```

---

# Create Virtual Environment

Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

Linux/Mac:

```bash
python -m venv .venv
source .venv/bin/activate
```

---

# Install Dependencies

```powershell
pip install -r requirements.txt
```

---

# Running Validation Tests

Execute:

```powershell
python -m pytest
```

```text
All required tests pass.
```

# Data Processing Workflow

The workflow consists of:

1. Data ingestion
2. Validation
3. Preprocessing
4. Feature extraction
5. Advanced feature extraction
6. Model training
7. Model evaluation
8. Report generation
