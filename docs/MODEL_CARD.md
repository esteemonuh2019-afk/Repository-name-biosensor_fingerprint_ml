# Model Card

## Model Name

Whole-Cell Biosensor Contaminant Fingerprinting Model

---

## Objective

The objective of this model is to identify environmental contaminants from temporal luminescence responses generated by engineered whole-cell biosensors.

---

## Scientific Question

Can contaminant-specific luminescence fingerprints be used to accurately classify environmental contaminants while maintaining performance across independent experiments?

---

## Input Data

Input features are derived from luminescence time-series measurements generated by:

* BL011
* BL027
* BL029
* BL030
* BL031
* BL032

biosensor strains.

---

## Target Classes

* Boric Acid
* DEET
* Diazinon
* Metaldehyde
* Propoxur
* Trimethoprim

---

## Feature Set

### Original Features

* Area Under Curve (AUC)
* Maximum Signal
* Minimum Signal
* Time-to-Peak
* Initial Slope
* Final Signal

### Advanced Features

* Peak-to-Baseline Ratio
* Fold Change
* Maximum Derivative
* Minimum Derivative
* Signal Decay Rate
* Early AUC
* Mid AUC
* Late AUC

---

## Validation Approach

### Stage 1: Random Train/Test Split

Purpose:

Evaluate baseline classification performance.

Observed outcome:

* Classification performance approximately 98%

Limitation:

* Potential experiment leakage
* May overestimate generalization ability

---

### Stage 2: Leave-One-Experiment-Out (LOEO)

Purpose:

Evaluate experiment-independent performance.

Observed outcome:

* Significant performance reduction relative to random split
* Revealed experiment-to-experiment variability

Scientific value:

* More realistic estimate of deployment performance

---

## Model Refinement

Additional analyses included:

* Feature importance analysis
* Strain ablation analysis
* Panel optimization
* Per-chemical evaluation
* Chemical-specific strain ranking
* Advanced temporal feature engineering

---

## Key Findings

### Finding 1

Random train/test performance substantially overestimated generalization performance.

### Finding 2

LOEO validation revealed experiment-dependent variability.

### Finding 3

BL027 emerged as the strongest overall biosensor strain.

### Finding 4

Different contaminants exhibited strain-specific recognition patterns.

### Finding 5

Advanced temporal features improved experiment-independent classification.

---

## Interpretability

Interpretability was supported through:

* Feature importance analysis
* Per-chemical performance analysis
* Confusion matrix analysis
* Strain-specific ranking analysis

---

## Limitations

* No external validation dataset
* Single biosensor platform
* Some contaminant overlap remains
* Diazinon remains difficult to distinguish using universal models

---

## Intended Use

Research use only.

Designed for:

* Biosensor evaluation
* Contaminant fingerprinting
* Machine learning research
* Biosensor optimization studies

---

## Ethical and Safety Considerations

The model should not be used for:

* Clinical diagnosis
* Regulatory enforcement
* Environmental compliance decisions

without additional validation.
